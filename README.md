# cloudflare-monorepo-react-ts-template

This is a minimal Cloudflare monorepo React + TypeScript template scaffold created from an existing project. It contains placeholders and minimal entry files so you can quickly start new projects with a similar layout.

Quick start:

1. cd into the folder

```bash
cd survive-at-all-costs-template
```

2. Initialize git, install dependencies and run dev server

```bash
git init
npm install
npm run dev
```

Notes:

- Replace placeholders in [workers](workers), [shared](shared), and other directories with your app code.
- Add Cloudflare `wrangler.toml` values and secrets as needed.
